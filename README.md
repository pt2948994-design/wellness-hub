# 💚 Wellness Hub - Smart Health Platform

A modern, responsive smart health website designed to help users track their wellness, book doctor appointments, and maintain a healthier lifestyle.

## 🌟 Features

### 1. **Health Tracking Dashboard**
   - Track heart rate (bpm)
   - Monitor blood pressure (mmHg)
   - Log weight measurements
   - Record daily steps
   - View historical health records
   - Data stored locally in browser

### 2. **Doctor Appointment System**
   - Browse available doctors by specialty
   - Book appointments with selected date and time
   - Manage appointment schedule
   - Appointment confirmation status
   - Appointment history

### 3. **Services**
   - 📊 Real-time health tracking
   - 👨‍⚕️ Doctor appointment booking
   - 💊 Medication reminders
   - 🏋️ Personalized fitness plans

### 4. **Responsive Design**
   - Mobile-friendly interface
   - Tablet and desktop optimization
   - Smooth navigation
   - Beautiful gradient UI

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/pt2948994-design/wellness-hub.git
cd wellness-hub
```

2. Open in browser:
   - Simply open `index.html` in your web browser
   - Or use a local server:
```bash
python -m http.server 8000
# Then navigate to http://localhost:8000
```

## 💻 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Storage**: LocalStorage for client-side data persistence
- **Responsive**: CSS Grid and Flexbox
- **Browser Compatible**: All modern browsers

## 📋 How to Use

### Track Your Health
1. Navigate to "Health Tracker" section
2. Enter your vital signs:
   - Heart rate
   - Blood pressure
   - Weight
   - Steps walked
3. Click "Save Data"
4. View your health records history

### Book an Appointment
1. Go to "Appointments" section
2. Fill in your details:
   - Your name
   - Select doctor
   - Choose date
   - Select time
3. Click "Book Appointment"
4. View your booked appointments

## 🔒 Data Privacy

- All health data is stored locally in your browser
- No data is sent to external servers
- Data persists in LocalStorage
- Clear browser data to remove stored information
